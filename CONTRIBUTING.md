# Contributing

Ideas, feedback, issues, and pull requests are very welcome.

- Propose an idea, question, or bug: open a [GitHub Issue](https://github.com/XR-Lee/Gemcp/issues). This repository uses Issues for that.
- Send a change: branch from `main` and open a pull request against `main`.
- Gemcp is released under the [MIT License](LICENSE). Contributions are accepted under the same license.

The same note, with a little more detail, is [Contributing](README.md#contributing) in the English README.
